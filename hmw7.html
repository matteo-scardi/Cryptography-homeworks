Statistical Independence

Contingency tables, expected frequencies under independence and the chi-square test

📚 Project Description

Given a bivariate dataset (X, F), this page builds the contingency table from the raw pairs, computes joint, marginal and conditional frequencies, derives the expected frequencies under independence, and runs the chi-square test with its p-value. A permutation test checks the result without the chi-square approximation, and a closing tab separates statistical association from causality.

P(X=i, F=j) = P(X=i)·P(F=j)  |  Eij = RiCj/N  |  χ² = Σ(Oij − Eij)²/Eij, df = (r−1)(c−1)

Everything runs locally in your browser.

The default text is only a tiny example: the expected counts will be below 5 and the page will warn you.

Independence in probability

Events A and B are independent iff P(A∩B) = P(A)P(B), equivalently P(A|B) = P(A) when P(B) > 0: knowing B does not change the probability of A.

For two categorical variables X (r categories) and F (c categories), independence means, for every cell:

P(X=i, F=j) = P(X=i)·P(F=j)  ⇔  P(F=j | X=i) = P(F=j) for all i

So all the rows of the conditional table (F given X) must be equal to the marginal distribution of F.

Hypotheses

  • H0: X and F are independent.
  • H1: X and F are dependent (associated).

Procedure

  1. Count the pairs: observed table Oij, totals Ri, Cj, N.
  2. Joint, marginal and conditional relative frequencies.
  3. Expected counts under H0: Eij = Ri·Cj/N.
  4. Statistic χ² = Σ(O−E)²/E, with df = (r−1)(c−1).
  5. p-value P(χ²df ≥ χ²obs) = Q(df/2, χ²/2) (regularized upper incomplete gamma).
  6. Reject H0 if p < α. Effect size: Cramér’s V = √(χ² / (N·min(r−1, c−1))).

Validity: the χ² approximation is reliable when almost all expected counts are at least 5 (rule of thumb: no expected count below 1 and at most 20% below 5).

Python

import numpy as np
from scipy.stats import chi2
O = np.array(table)                  # observed counts
E = O.sum(1, keepdims=True) * O.sum(0, keepdims=True) / O.sum()
stat = ((O - E) ** 2 / E).sum()
df = (O.shape[0] - 1) * (O.shape[1] - 1)
p = chi2.sf(stat, df)

Test result

Conditional distributions vs marginal

Each bar is the distribution of F within one category of X (100% stacked). The last bar is the marginal distribution of F. If X and F were independent, all bars would look alike.

Permutation test

Shuffling the F labels breaks any link with X while keeping both marginals fixed. Repeating it 2000 times gives the distribution of χ² under independence, to compare with the observed value and with the theoretical χ²df density.

Reading the result

  • p < α: the observed table would be very unlikely if X and F were independent, so we reject H0. The variables are statistically dependent.
  • p ≥ α: no evidence of dependence. This does not prove independence: the test may simply lack power (small N).
  • Significance is not strength. χ² grows with N, so a huge sample can make a negligible association significant. Cramér’s V does not grow with N and measures the effect size.
  • The test is global. It says that some cells differ from independence; the standardized residuals say which.
  • No direction. χ² is symmetric: it cannot say whether X influences F, F influences X, or neither.

Association is not causation

  • Confounding: a third variable Z can drive both X and F. Example: ice-cream sales and drownings are associated, both depend on temperature.
  • Reverse causality: F may cause X rather than the other way round.
  • Simpson’s paradox: an association in the pooled table can vanish or reverse inside every subgroup of Z.
  • Selection and design: only randomised experiments, or careful causal modelling, support causal claims.
  • Titanic example: class and survival are strongly associated, but class is entangled with sex, age and cabin location, so the table alone does not show that class caused survival.

Sample size changes χ² but not V

Multiplying every observed count by k (same proportions) multiplies χ² by k, shrinks the p-value, and leaves Cramér’s V unchanged.
