Welford’s Recurrence Formulas

Homework 5 – Online mean, sum of squares and variance in three lines

📚 Project Description

Knuth’s recurrence updates the mean one observation at a time. Following the same idea, this page derives Welford’s recurrences for the sum of squares SS and for the variance, implements them with a core of only three lines, and compares them with the naive one-pass formula on data with a large offset, where the naive method loses all its precision.

Mn = Mn−1 + (xn − Mn−1)/n  |  SSn = SSn−1 + (xn − Mn−1)(xn − Mn)

Everything runs locally in your browser.

Step 1: Knuth’s recurrence for the mean

From n·Mn = (n−1)·Mn−1 + xn:

Mn = Mn−1 + (xn − Mn−1)/n

Define the innovation d = xn − Mn−1. Then:

Mn = Mn−1 + d/n
xn − Mn = d − d/n = d·(n−1)/n

Step 2: Welford’s recurrence for SS

Let SSn = Σ(xi − Mn)² = Σxi² − n·Mn². Subtract consecutive terms:

SSn − SSn−1 = xn² − n·Mn² + (n−1)·Mn−1²

Write M = Mn−1, so that xn = M + d and Mn = M + d/n:

xn² = M² + 2Md + d²
n·Mn² = nM² + 2Md + d²/n

Substituting, the terms in M cancel (M² − nM² + (n−1)M² = 0, and 2Md cancels):

SSn − SSn−1 = d²(1 − 1/n) = d²(n−1)/n

Since (xn − Mn−1)(xn − Mn) = d · d(n−1)/n:

SSn = SSn−1 + (xn − Mn−1)(xn − Mn),   SS0 = 0, M0 = 0

Step 3: Recurrences for the variance

Population variance σ²n = SSn/n

From nσ²n = (n−1)σ²n−1 + d²(n−1)/n:

σ²n = σ²n−1 + [ (n−1)d²/n − σ²n−1 ] / n

Sample (unbiased) variance s²n = SSn/(n−1), n ≥ 2

From (n−1)s²n = (n−2)s²n−1 + d²(n−1)/n:

s²n = ((n−2)/(n−1))·s²n−1 + d²/n

Check, n = 2: s²2 = d²/2 = (x2 − x1)²/2, which is the correct variance of two points.

Why it works well

  • Each update adds a term d·(x − Mn) ≥ 0: no subtraction of large nearly-equal numbers.
  • One pass, O(1) memory, usable on streams.
  • SSn is never negative (up to rounding), unlike the naive formula.

JavaScript

// state: n = 0, mean = 0, ss = 0
function update(s, x) {
  const d = x - s.mean; s.n++;          // innovation
  s.mean += d / s.n;                    // Knuth
  s.ss   += d * (x - s.mean);           // Welford
}
const popVar    = s => s.ss / s.n;
const sampleVar = s => s.ss / (s.n - 1);

Python

n = mean = ss = 0.0
for x in data:
    n += 1; d = x - mean
    mean += d / n
    ss += d * (x - mean)
var_sample = ss / (n - 1)

C

double mean = 0.0, ss = 0.0; long n = 0;
for (long i = 0; i < len; i++) {
    double d = x[i] - mean; n++;
    mean += d / n;
    ss   += d * (x[i] - mean);
}
double var = ss / (n - 1);

Notes

  • The core is three statements: compute d, update the mean, update ss. The counter increment is bookkeeping.
  • The last factor uses the new mean. Using the old mean in both factors would give d² and a wrong result.
  • For n = 1 the sample variance is undefined (division by zero), so guard it.
  • Equivalent form: ss += d²(n−1)/n, using only the old mean.

Step-by-step recurrence

Welford vs naive formula

Data: xi = offset + ui, with ui pseudo-uniform in [0,1), so the true variance is about 1/12 ≈ 0.083 whatever the offset. The naive formula is (Σx² − (Σx)²/n)/(n−1). The reference is the two-pass method (mean first, then squared deviations).

A negative or wildly wrong naive variance is the classic symptom of catastrophic cancellation.

Relative error vs offset

Log–log scale; errors of exactly 0 are drawn at 10−17. Welford stays near machine precision, while the naive error explodes once the offset squared exceeds about 1016 times the variance.

Merging two partial results (Chan et al.)

If two streams A and B have (nA, MA, SSA) and (nB, MB, SSB), with δ = MB − MA and n = nA + nB:

M = MA + δ·nB/n
SS = SSA + SSB + δ²·nA·nB/n

With nB = 1 and SSB = 0 this reduces exactly to Welford’s update, because δ = d and nA/n = (n−1)/n. It allows parallel or distributed computation: each worker processes a chunk, then the results are merged.
