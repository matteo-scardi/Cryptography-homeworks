Elliptic-Curve Scalar Multiplication (ECDLP)

Toy Model: y² ≡ x³ + 7 (mod 17) — Ethereum secp256k1 Key Derivation Prototype

📚 Theoretical Overview & Homework Context

In modern blockchain architectures such as Ethereum, accounts and digital identities are governed by Public-Key Cryptography based on Elliptic Curves. Ethereum specifically utilizes the secp256k1 standard curve: y² ≡ x³ + 7 (mod p), where p is a massive 256-bit prime number.

How Key Derivation Works: A user picks a random secret integer k called the Private Key. The corresponding Public Key is computed as the geometric point multiplication Q = k · G, where G is a globally agreed generator (base point). While computing Q = k · G is computationally trivial via modular arithmetic (using the Double-and-Add algorithm in O(log k) operations), reversing this calculation — determining the secret scalar k given only Q and G — is known as the Elliptic Curve Discrete Logarithm Problem (ECDLP). Solving the ECDLP takes infeasible exponential/sub-exponential time (O(√n) steps), making scalar multiplication an algebraic One-Way Function (OWF).

Our Toy Model: To visualize every discrete point and understand the group law arithmetic without handling 256-bit astronomical numbers, this application implements the exact secp256k1 parameters scaled down to the finite field ℤ₁₇ (p = 17, a = 0, b = 7), with base point G = (1, 5) and group order n = 19 (including the neutral point at infinity 𝒪).

Cryptographic Analysis: One-Way Functions vs Hash Functions

🔒 Elliptic Curve Scalar Multiplication (k · G)

  • One-Way Function (OWF): Easy forward: O(log k) using the Double-and-Add algorithm. Hard in reverse: requires solving the ECDLP, which takes O(√n) steps using Pollard's rho algorithm.
  • Preserves Group Homomorphism: (k₁ + k₂)G = k₁G + k₂G. This algebraic linearity is vital for Schnorr signatures, ECDSA, ring signatures, and zero-knowledge proofs.
  • Non-Uniformity: The points are strictly constrained to the 1-dimensional elliptic curve abelian group. They do not fill the 2D space ℤ_p × ℤ_p uniformly.

⚡ Cryptographic Hash Functions (Keccak-256)

  • Destroys Homomorphism: Hash functions explicitly destroy algebraic structure: H(x + y) ≠ H(x) + H(y).
  • Strict Avalanche Criterion (SAC): Flipping a single bit of the input flips approximately 50% of the output bits with zero correlation.
  • Uniform Random Oracle: Output bits are statistically indistinguishable from uniform white noise across the entire 256-bit digest space.
