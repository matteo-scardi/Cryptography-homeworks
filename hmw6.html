Riemann vs Lebesgue Integration & the Normal CDF

Numerical integration by domain and range partitions, and the numerical computation of Φ(x)

📚 Exercise 1: Riemann and Lebesgue Integration

Seven test functions plus two pathological ones (Dirichlet, Thomae) are integrated numerically in two ways. The Riemann approach partitions the domain into subintervals. The Lebesgue approach partitions the range into levels and measures the preimages of the level sets. The page compares accuracy, convergence and cost, and shows where the two approaches behave differently.

Riemann: Sn = Σ f(ξi)·Δx  |  Lebesgue: LK = Σ yj·μ(f−1((yj, yj+1]))  |  ∫f = ∫0∞ μ{f > t} dt

Everything runs locally in your browser.

Riemann: partition the domain

Split [a, b] into n cells of width h = (b−a)/n, pick a tag ξi in each cell:

Sn = h · Σi f(ξi)

Left, right or midpoint tags. For a smooth f the error is O(h) for the left sum and O(h²) for the midpoint sum. The cost is n evaluations of f. The Darboux sums use inf and sup on each cell. f is Riemann-integrable iff they converge to the same limit, which happens iff f is bounded and its discontinuities have measure zero.

Lebesgue: partition the range

Split [lo, hi] into K levels yj = lo + j·δ, and let Ej = {x : yj < f(x) ≤ yj+1}:

LK = Σj yj · μ(Ej)   (lower simple function, error ≤ δ·(b−a))

Two ways to obtain μ(Ej):

  • Exact preimage: through the distribution function D(t) = μ{f > t} (analytic formula or root finding), so μ(Ej) = D(yj) − D(yj+1).
  • Sampled preimage: evaluate f at N grid points and count how many fall in each level.

Code (Python)

# Riemann (midpoint)
h = (b - a) / n
R = h * sum(f(a + (i + 0.5) * h) for i in range(n))

# Lebesgue (sampled preimages), lo/hi = range of f
d = (hi - lo) / K;  cnt = [0] * K;  h = (b - a) / N
for i in range(N):
    v = f(a + (i + 0.5) * h)
    cnt[min(K - 1, int((v - lo) / d))] += 1     # which level set contains x?
L = h * sum((lo + j * d) * cnt[j] for j in range(K))   # mu(E_j) ~ cnt[j] * h

Observation: if K is about N, every level contains only a few sample points and L is essentially the midpoint Riemann sum with the values rounded down. The conceptual difference is not in the arithmetic but in what is required of f: Riemann needs good behaviour of f on intervals, Lebesgue only needs the preimages to be measurable.

Dirichlet function: 1 on the rationals, 0 on the irrationals

Floating-point numbers are all rational, so f cannot be sampled on a computer in the usual way. The tags below are therefore symbolic: the rational tag is k/n and the irrational tag is (k + √2/2)/n. An oracle returns 1 or 0 according to the type of the tag.

  • Riemann: in every cell inf = 0 and sup = 1, so the lower and upper Darboux sums are 0 and 1 for every n. The Riemann sum can be made 1 or 0 (or anything in between) by choosing the tags, so no limit exists: f is not Riemann-integrable.
  • Lebesgue: the range is {0, 1}, f−1({1}) = ℚ∩[0,1] is countable, so μ = 0 and ∫f = 1·0 + 0·1 = 0. Random tags are irrational with probability 1, which is the sampling-based version of this answer.

Thomae function: f(p/q) = 1/q (lowest terms), 0 on the irrationals

f is continuous at every irrational point and discontinuous at every rational one. The discontinuity set has measure zero, so f is Riemann-integrable and the two integrals agree, both equal to 0.

Left sum with rational tags k/n: (1/n)Σ gcd(k,n)/n. Upper Darboux sum: on each closed cell the sup is 1/qmin, where qmin is the smallest denominator of a fraction inside the cell. The lower Darboux sum is 0 because every cell contains irrationals. Both sums tend to 0.

Lebesgue view: the level sets {f ≥ 1/m} are finite

For every m the set {f ≥ 1/m} contains only fractions with denominator ≤ m. It is finite, so it has measure 0, and every level set above 0 contributes nothing: ∫f = 0.

Do the two approaches converge to the same value?

  • Yes, for Riemann-integrable functions. If f is Riemann-integrable it is Lebesgue-integrable and the two integrals coincide. The tables show both sums approaching the exact value for sin, x², |x−0.5|, the two step functions and sin(x)/x.
  • Thomae: both give 0.
  • Dirichlet: Riemann does not exist, Lebesgue gives 0. Lebesgue integrability is strictly more general.
  • 1/√x: unbounded, so only an improper Riemann integral exists (limit of ∫ε1). The Lebesgue integral exists directly and equals 2. Numerically both converge slowly, roughly like the square root of the budget, because the singularity is hard to resolve with either partition.

Accuracy, convergence and cost

  • Smooth f: the midpoint Riemann sum has error O(1/n²), the left sum O(1/n), the Lebesgue lower sum O(1/K) (it is a lower sum with level width δ). With exact preimages Lebesgue is therefore less efficient on smooth functions.
  • Jumps: Riemann loses one cell around the jump, so the error is O(1/n). Lebesgue quantisation also gives O(1/K), but the preimages of the level sets are exact intervals, so no accuracy is lost around the jump itself.
  • Cost: Riemann is trivially cheap and needs no knowledge of f besides evaluations. Lebesgue with exact preimages needs the distribution function of f (analytic or root finding), which is problem-specific. The sampled variant has the same cost as Riemann but a worse constant.
  • Why Lebesgue matters: not for speed on textbook integrands, but because it handles wild functions, unbounded functions and limits of functions (monotone and dominated convergence), which is the foundation of probability and of expectations such as E[X].

📚 Exercise 2: Numerical Computation of the Normal CDF

The standard normal CDF Φ(x) = ∫−∞x φ(t) dt has no elementary closed form (Liouville). It is expressed exactly with the error function, but computing erf is itself a numerical task. This exercise implements several methods (trapezoid, Simpson, Taylor series of erf, Marsaglia’s series, Abramowitz–Stegun approximations, continued fraction, and a hybrid), and compares their accuracy and cost with a reference.

Φ(x) = ½[1 + erf(x/√2)]  |  erf(z) = (2/√π) ∫0z e−t² dt

Everything runs locally in your browser.

Why no elementary antiderivative? (Liouville)

Criterion (Liouville, Ostrowski, Risch). Let f and g be rational functions with g non-constant. Then ∫ f·eg dx is elementary iff there is a rational function R with

R′ + g′·R = f,   and then ∫ f eg = R eg

For φ(t) ∝ e−t²/2 we have g = −x²/2, g′ = −x, f = 1, so we would need R′ − xR = 1.

  • If R is a polynomial of degree d ≥ 0, then R′ − xR has degree d+1 ≥ 1, never the constant 1. R = 0 gives 0.
  • If R has a pole of order m ≥ 1 at a point a, then R′ has a pole of order m+1 but xR only of order ≤ m, so R′ − xR still has a pole and cannot equal 1.

No such R exists, so ∫ e−t²/2 dt is not elementary: it cannot be written with finitely many exponentials, logarithms, roots and algebraic operations. The same holds for Φ.

The error function and why we still need numerics

Define erf(z) = (2/√π) ∫0z e−t² dt. Substituting t = s/√2:

Φ(x) = ½[1 + erf(x/√2)],   Q(x) = 1 − Φ(x) = ½ erfc(x/√2)

This is an exact analytic representation, but erf is a new special function, defined as the integral itself. Naming it does not make it computable: a CPU has only +, −, ×, ÷. Libraries therefore evaluate erf with minimax rational approximations on several intervals, series near 0 and continued fractions or asymptotic expansions in the tails.

Approaches implemented

  • Numerical integration: trapezoid and Simpson on ½ + ∫0xφ.
  • Series: Taylor series of erf (alternating) and Marsaglia’s series Φ(x) = ½ + φ(x)Σ x2k+1/(2k+1)!! (all terms positive).
  • erf-based approximations: Abramowitz–Stegun 7.1.26 (error < 1.5·10−7) and 26.2.17 (< 7.5·10−8).
  • Continued fraction for the tail: Q(x) = φ(x)/(x + 1/(x + 2/(x + 3/(x + …)))).
  • Hybrid: series for |x| < 3, continued fraction beyond. It keeps almost full double precision, including a good relative accuracy in the tails.

Recommended implementation (Python)

from math import exp, pi, sqrt
phi = lambda x: exp(-x*x/2) / sqrt(2*pi)

def Phi(x):
    if abs(x) < 3:                       # Marsaglia series: all terms positive, no cancellation
        t = s = x
        for k in range(1, 400):
            t *= x*x / (2*k + 1); s += t
            if abs(t) < 1e-18 * abs(s): break
        return 0.5 + phi(x) * s
    a = abs(x); f = a                    # tail: continued fraction evaluated backwards
    for k in range(120, 0, -1): f = a + k / f
    q = phi(a) / f                       # Q(|x|), accurate even for Q ~ 1e-16
    return 1 - q if x > 0 else q

Methods based on ½ + ∫0x lose all relative accuracy in the lower tail, where Φ is tiny: they subtract two numbers close to 0.5. The erf Taylor series also suffers from cancellation, since its terms grow up to about ez² before shrinking. The tail needs the complementary formulation.

The Taylor series of erf is alternating and its terms grow to about ez² with z = x/√2, so the error plateaus well above 10−16 for larger x. Marsaglia’s series has only positive terms and reaches full precision.

Efficiency summary

Main findings

  • Quadrature: simple and flexible, but needs hundreds of exponentials per evaluation to reach 10−12 with Simpson. It cannot give relative accuracy in the lower tail.
  • Series: excellent near the centre. The alternating Taylor series of erf degrades as |x| grows. The non-alternating form avoids this and needs about x² + O(1) terms.
  • A&S approximations: a handful of operations and one exponential, accuracy 10−7 to 10−8, enough for many practical purposes but not for precise tails.
  • Continued fraction + series (hybrid): near double precision everywhere, with a bounded cost.

Why the theory still matters

  • Liouville’s theorem explains why no finite formula in elementary functions can replace the integral: every method is an approximation scheme with a controlled error.
  • erf gives a precise name and an exact identity Φ = ½(1 + erf(x/√2)), useful for proofs and for moving between Φ, erf and erfc, but computing its value is the same numerical problem.
  • The accuracy target matters: a 10−7 approximation is fine for a z-table, but p-values of 10−15 or log-likelihoods in the tails require the complementary function and a method with good relative accuracy.
