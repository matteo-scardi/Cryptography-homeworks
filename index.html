Cryptographic Analysis: OWF vs Hash Functions

Elliptic Curve Multiplication (k · G)

  • One-Way Function (OWF): Easy forward: \(O(\log k)\) via Double-and-Add. Hard backwards: requires solving the ECDLP (\(O(\sqrt{n})\) Pollard-rho).
  • Algebraic Homomorphism: Preserves structure: \((k_1 + k_2)G = k_1 G + k_2 G\). Crucial for Schnorr signatures, ECDSA, and threshold cryptography.
  • Non-Uniformity: Outputs are strictly constrained to the curve's abelian group manifold; coordinates are not uniform integers.

Cryptographic Hash Functions (Keccak-256)

  • Destroys Homomorphism: Zero algebraic relations remain: \(H(x + y) \neq H(x) + H(y)\).
  • Strict Avalanche Criterion (SAC): Flipping 1 input bit flips exactly ~50% of the output bits with zero correlation.
  • Uniform Random Oracle: Output distribution is indistinguishable from a true uniform random bit generator.
